# 🐎 Horse Race Simulation

A console-based C++ project that simulates a horse race, leveraging object-oriented programming (OOP) principles. This project was developed to demonstrate the application of classes, inheritance, and dynamic memory allocation in C++.

## 🎯 Project Overview

This simulation models a horse race where each horse progresses randomly across the track. The race continues until one of the horses reaches the finish line. The simulation provides a visual representation of the race's progress in the console.

## 💡 Features

- **Object-Oriented Design**: Utilizes classes to represent horses and the race track.
- **Randomized Movement**: Each horse advances by a random number of steps in each iteration.
- **Console Visualization**: Displays the race track and horse positions in the console after each iteration.
- **Dynamic Memory Allocation**: Manages horse objects using dynamic memory to allow flexible race configurations.
